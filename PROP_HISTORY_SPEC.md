# Player Prop History Tracking — Build Spec

## Context
Read CLAUDE.md first for full project context. This spec adds player prop outcome
tracking to the Statalizers pipeline. The goal is to log whether each prop pick
hit (over/under), surface hit rates in the /performance dashboard, and feed
trailing hit rates back into prop confidence scoring.

## CRITICAL — API Quota Warning
**Do NOT call any live APIs while implementing or testing this spec.**
- The Odds API has a 500 req/month free tier (currently at ~273 used). Every
  pipeline run or test that triggers mlb_odds_scraper burns quota. Do not run
  run_pipeline.py, force-pipeline, or any scraper that hits the Odds API.
- Safe to call: MLB Stats API (no key, no quota), Baseball Savant (no key),
  Open-Meteo weather (no key), Polymarket (no key).
- All testing must be done with `python -m py_compile` syntax checks and direct
  DB/function unit tests only — never a full pipeline run.
- If you need to verify the grading logic works, mock the API response in a
  local test rather than hitting the live MLB Stats API more than once.

### Part 1 — DB Schema: `player_prop_history` table

Add to `db/schema.py` alongside the existing tables:

```sql
CREATE TABLE IF NOT EXISTS player_prop_history (
    id              SERIAL PRIMARY KEY,
    game_date       DATE NOT NULL,
    player_name     TEXT NOT NULL,
    team            TEXT,
    away_team       TEXT,
    home_team       TEXT,
    prop_type       TEXT NOT NULL,   -- 'HR', 'HITS', 'TB', 'RBI', 'R', 'SB', 'K'
    line            NUMERIC(4,1) NOT NULL,
    actual_value    NUMERIC(5,1),    -- NULL until graded
    result          TEXT,            -- 'OVER', 'UNDER', 'PUSH', NULL until graded
    model_conf      NUMERIC(5,3),    -- model confidence at pick time (0-1)
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    graded_at       TIMESTAMPTZ,
    UNIQUE (game_date, player_name, prop_type, line)
);
CREATE INDEX IF NOT EXISTS idx_prop_history_player ON player_prop_history (player_name, prop_type);
CREATE INDEX IF NOT EXISTS idx_prop_history_date ON player_prop_history (game_date);
```

### Part 2 — Nightly Grading: log prop outcomes

Modify `run_analysis.py` to grade prop picks nightly alongside game picks.

After the existing `push_grades_to_db()` call, add `grade_prop_outcomes(date)`:

```python
def grade_prop_outcomes(date: str):
    """
    For each player in player_prop_history with game_date=date and result=NULL,
    fetch the actual box score stat from MLB Stats API and grade the prop.
    
    MLB Stats API endpoint for box score:
    https://statsapi.mlb.com/api/v1/game/{game_pk}/boxscore
    
    Stat mapping:
      HR    -> batting.homeRuns
      HITS  -> batting.hits
      TB    -> batting.totalBases
      RBI   -> batting.rbi
      R     -> batting.runs
      SB    -> batting.stolenBases
      K     -> pitching.strikeOuts  (for SP props)
    
    Grade logic:
      actual > line  -> OVER
      actual < line  -> UNDER
      actual == line -> PUSH
    
    Use the schedule master CSV or DB to get game_pk for the date.
    Non-fatal: log warnings and continue if any game/player lookup fails.
    """
```

### Part 3 — Props confidence: wire trailing hit rate into scoring

Modify `model/mlb_props_model.py` in the `score_prop()` function (or wherever
final confidence is set per prop pick):

```python
from db.picks_store import get_player_trailing_hit_rate

def _apply_trailing_hit_rate(player_name, prop_type, line, base_conf, days=30):
    """
    Blend model base confidence with player's trailing hit rate.
    
    Blend formula (only applied if >= 5 graded results exist):
      blended = 0.70 * base_conf + 0.30 * trailing_hit_rate
    
    If trailing hit rate >= 0.65: add +2% confidence bonus
    If trailing hit rate <= 0.40: subtract -3% confidence penalty
    
    Cap final confidence at 0.92, floor at 0.40.
    Log the adjustment so it's visible in Railway logs.
    Returns base_conf unchanged if no history exists yet.
    """
```

Add a `trailing_hit_rate` field to the prop pick output dict so it shows
in the dashboard card reasoning section (e.g. "Hit this prop 18/24 last 30d").
